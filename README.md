- **Visuals & Charts**: Recharts
- **Deployment Ready**: Optimized chunks (< 100 kB initial bundle)

## 💻 Quick Start & Commands

```bash
# 1. Install dependencies
npm install

# 2. Run the development server (runs on http://localhost:3000)
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build locally
npm run preview
```
